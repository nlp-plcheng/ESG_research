Reading it

  • AI judged wrong / Label changed: both near 0% usually means clicking “correct” all the way down without reading. Far above the team figure may mean a different standard — look at that person's calibration answers first.
  • Source page: wrong is a retrieval-precision problem in the pipeline (the commitment is real, the reference is off); not found means the pipeline produced a commitment that is nowhere in the report. Two different things — never sum them. If one person's “not found” count is far above the rest, check they know to search the full report before ticking it.
  • Never opened (red): the item was answered without opening a single evidence page. One or two is normal; a pattern is worth asking about.
  • Min/item: only time actually spent in that tab (switching away and idling do not count), so these are directly comparable between people.
  • Q1 / median / Q3: this person's values (estimates per year; minutes and look-ups per item) sorted, and the values a quarter, half and three quarters of the way up. A median close to the team's but a wide Q1–Q3 means the answers swing a lot. The team row pools everyone's values; it is not the average of the personal medians.
  • Calibration ✗: non-zero only when ESG_GOLD_FILE is set with expect values. The automatic calibration items carry no expected answer, so both columns stay 0.

This page only reads the database and writes nothing, so it is safe to open at any time. Crop the PID column out of any screenshot — those ids are credentials.
